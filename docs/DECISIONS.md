# Decisions Log

Record accepted changes to docs/SPEC.md here, newest first.

| Date | Decision | Reason |
|------|----------|--------|
| 2026-10-01 | The ElevenLabs Scribe transcription backend moves to M5. | It's a paid API, and the ElevenLabs docs get read once, together with the music work. |
| 2026-10-01 | Additions to the CLI surface: a `status` command, and `--run` accepts an ID, a unique prefix, a path or `latest` (the default). `--transcript`, `--whisper-model`, `--language` and `--isolate-voice` stick to the run as manifest `options`. New modules: `pipeline.py`, `costs.py`, `errors.py`, `text/`, `backends/transcribe_base.py`, `backends/isolate_*.py`. | Makes the cache state visible, and stops a later command from silently re-running a 15-minute ASR because a flag was omitted. |
| 2026-10-01 | `costs.json` is a JSON array. Entries are only ever appended, and the file is rewritten atomically right after each paid call. | Keeps the spec's file name and "append-only" semantics. |
| 2026-10-01 | `--dry-run` executes nothing, not even free local stages. It prints which stages would run and which are cached, plus paid estimates (from cached artifacts or heuristics), then exits. A paid call without `--yes` needs an interactive confirmation and refuses when there's no TTY. | Predictable and free of side effects, and money is never spent implicitly. |
| 2026-10-01 | Presets get an optional `clips:` block (`count` 5, `min_seconds` 3, `max_seconds` 15, `total_speech_seconds` 60, `fade_ms` 15, `boundary_search_ms` 150). `--clips N` overrides the count. | Stage 3 needs these targets, and neither the spec's presets nor its config had a place for them. |
| 2026-10-01 | `00_source.wav` is 44.1 kHz **32-bit float**, resampled with soxr (VHQ). It switches to RF64 above 4 GB, and ffmpeg's bitexact flags make it hash-stable. Loudness and peaks are measured with ffmpeg's `ebur128` filter, which streams. | Float keeps MP3 inter-sample overs instead of clipping them, reproducible bytes keep caches valid, and measurement uses constant memory on long talks. |
| 2026-10-01 | The exactness invariant: `clips/*.wav` and the dry `07_mix/stems/speech.wav` are sample-exact slices of the analysis source multiplied by the fade envelope. Gain, EQ, compression and effect sends are applied only on the mix bus. With `--isolate-voice`, the analysis source is `01_clean.wav`, and the manifest records which file clips were cut from. | Resolves the conflict between Goal 3 (bit-exact apart from fades), section 2 ("level changes") and the section 7 processing chain. |
| 2026-10-01 | Alignment flags official text that isn't spoken (captions, headings) as `unspoken` and excludes it from `words` and `sentences`. ASR-only runs of 4+ words become `source: "asr"` sentences. If under 20% of ASR words match the official text, alignment warns and falls back to an ASR-only transcript. | The sample transcript has 12 caption and heading lines. Interpolated timestamps would turn them into fake, selectable "sentences". |
| 2026-10-01 | The pipeline is split into cached sub-stages. The CLI `ingest` runs `ingest` + `isolate`, and the CLI `transcribe` runs `asr` + `align`, which adds the artifact `02_asr.json` (raw ASR output). | Re-aligning, with or without an official transcript, doesn't re-run Whisper. |
| 2026-10-01 | Python ≥3.12 with exact `==` pins for direct dependencies, plus `uv.lock`. torch comes from the PyTorch CPU index, and Intel Macs are excluded from lock resolution. | numpy 2.5 and PyAV 19 need Python 3.12. The Linux torch on PyPI pulls about 3 GB of CUDA libraries, and demucs 4.1 pins numpy<2 on Intel Macs. |
| 2026-10-01 | Voice isolation is implemented in M1 using demucs 4.1.0 (`htdemucs`) as the optional `isolate` extra. The audio is processed in windows with extra context and crossfades, and streamed to disk. | Your choice. Processing in windows keeps memory bounded on hour-long lectures. |
| 2026-10-01 | The default Whisper model is `large-v3-turbo` (the spec's config example said `small`). | Your choice: better names, punctuation and word timings. It takes about 10–20 min of CPU per 13-minute talk and is then cached. |
